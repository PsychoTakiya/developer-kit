# Preface & Philosophy

This book curates deep React engineering knowledge from the existing repository docs and expands them with structured explanations, patterns, and decision frameworks.

## Goals

- Provide senior-level clarity on core mechanisms (rendering, concurrency, state).
- Offer pragmatic guidance for production concerns (performance, testing, accessibility, security).
- Serve as an interview preparation companion and on-boarding manual.

## Structure

Each chapter follows a consistent pattern:

1. Concept Overview
2. Deep Theory & Internals
3. Practical Examples
4. Pitfalls & Anti-Patterns
5. Decision Guidelines / Trade-offs
6. References & Further Reading

## Source Materials

Derived from: `REACT_MASTERY_GUIDE.md`, `Hooks_Deep_Dive.md`, `STATE_MANAGEMENT.md`, `DESIGN_PATTERNS.md`, `REDUX_TOOLKIT.md`, `TANSTACK_QUERY.md`, and other repository examples.

## How to Revise

- Chapters 11–17 open each question with a **30-second answer**: the version you'd say out loud in an interview. Read those first; the detail underneath is for follow-ups.
- The [Night-Before Sheet](./16-interview-cheatsheet) has a one-page summary and self-test flashcards for the whole React section.
- Log weak topics in the [revision tracker](/start-here/revision-tracker).
