# 4. Job Search Playbook & Tracker

## Resume checklist (3.5 years, SWE II / Senior)

- [ ] **One page.** Recruiters spend seconds on the first pass.
- [ ] A 2-line summary at the top: title, years, core stack, the kind of problems you solve.
- [ ] Each bullet: **action verb + what you built + measurable impact**. "Reduced dashboard load time from 6s to 1.8s by route-based code splitting and fixing an N+1 query" beats "Worked on performance".
- [ ] At least half the bullets show **ownership or impact beyond your tickets**: led, designed, migrated, mentored, introduced.
- [ ] Skills section matches the job description's keywords (many companies screen with software first).
- [ ] Latest role has the most detail; older roles get 2–3 bullets.
- [ ] Links: GitHub (only if it's tidy), LinkedIn, portfolio or blog if you have one.
- [ ] No photo, no "objective" paragraph, no long list of every tool you've touched.
- [ ] Exported as a PDF with a clear file name: `FirstName_LastName_Resume.pdf`.
- [ ] LinkedIn headline and "open to work" (recruiters only) updated to match.

### Bullet formula

> **[Verb]** [what] **using** [how/tech], **resulting in** [measurable outcome].

| Weak | Strong |
|---|---|
| Developed REST APIs in Node.js | Designed and built 12 REST endpoints for the billing service in Node/Express with Redis caching, cutting p95 latency from 800ms to 150ms |
| Worked on React frontend | Led migration of a 40-screen React app from class components to hooks and TanStack Query, removing 3k lines and halving data-fetching bugs |
| Helped new joiners | Created onboarding guide and pairing rotation that cut new-hire time-to-first-PR from 2 weeks to 4 days |

## Where to find roles

1. **Referrals**: the highest response rate by far. Ask former colleagues, college alumni and LinkedIn connections at target companies.
2. **Recruiters** reaching out on LinkedIn: keep your profile current and keyword-rich.
3. **Company career pages** directly (often better than job boards).
4. Job boards and communities relevant to your region and stack.

### Referral message template

> Hi [Name], hope you're doing well! I'm a [title] with 3.5 years in [React/Node/…], currently at [company], where I [one-line achievement]. I saw the [role] opening at [company] ([link]) and it looks like a great fit for my experience in [X]. Would you be open to referring me? I've attached my resume, and I'm happy to share anything else that would help. Thanks!

Keep it short, link the specific job, and make it easy to say yes.

## Weekly cadence

| Day | Focus |
|---|---|
| Mon–Fri mornings (60–90 min) | DSA: 1 new problem + scheduled redos |
| Mon / Wed evenings | System design: one building block or case study |
| Tue / Thu evenings | Tech depth (JS/React/Node) + flashcards |
| Saturday | One mock interview (coding or design), story bank practice out loud |
| Sunday | Applications and referrals, update trackers, plan next week |
